# PALETA PRINCIPAL

## Cor principal

Lilás:

`#A855F7`

Pode ser usada para:

- palavras-chave;
- destaques;
- seleções;
- detalhes de interface;
- linhas;
- pequenos elementos gráficos;
- pontos focais.

Nunca utilizar em excesso.

A cor deve orientar o olhar.

Não dominar toda a composição.

## Cores de apoio

- branco;
- preto;
- tons de cinza muito suaves;
- lilases de baixa opacidade;
- fundos claros com textura discreta.

Evitar adicionar novas cores sem função estratégica.

---

# FUNDO

O fundo padrão deve ser:

- branco;
- claro;
- limpo;
- com textura muito suave;
- sem gradientes fortes;
- sem manchas decorativas excessivas;
- sem elementos competindo com o conteúdo.

Gradientes podem aparecer de forma quase imperceptível.

Exemplo:

branco para lilás muito claro.

Nunca utilizar fundos pesados apenas para tornar a arte “mais chamativa”.

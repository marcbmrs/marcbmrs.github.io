# Local KORA

This directory connects Marcos Dev to KORA Core.

Start with:

```text
.kora/binding.md
```

KORA Core path:

```text
C:\KORA
```

## Local Owns

Marcos Dev owns:

```text
business identity
offers and services
client project context
brand and content strategy
website and campaign page decisions
publishing and deployment procedures
local agents, skills, tools, evals, automations, experiments, memory, and decisions
```

## Uses From KORA Core

KORA Core provides reusable:

```text
architecture
capability routing
context selection
skills
agents
knowledge
templates
eval patterns
governance and approval rules
maintenance and versioning patterns
```

## Daily Use

Useful natural requests:

```text
Vamos rodar o dia.
Tive uma ideia.
Isso esta repetitivo.
Vamos checar a saude.
Usa a KORA nesse projeto.
Verifica a instalacao da KORA.
Precisa de aprovacao?
Isso deveria virar skill local ou global?
```

## Default Flow

```text
Task or change
-> read .kora/binding.md
-> read AGENTS.md
-> select local context
-> use local agent/skill/tool/eval when project-specific
-> use KORA Core when reusable
-> check approval when risk or external side effects exist
-> record result, learning, decision, or capability gap only when useful
```

## Core Vs Local

```text
Reusable method -> KORA Core
Marcos Dev identity, offers, clients, channels, publishing, and deployment rules -> local .kora/ or project docs
Published website and client project files -> project repository
Secrets and credentials -> never in KORA Core or .kora/
```

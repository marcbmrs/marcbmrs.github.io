# Eval: Renan Browser UX Inspection Quality

## Purpose

Evaluate whether a browser-based UX inspection of the Renan Reformas panel produces useful, safe, and actionable findings.

## Criteria

- The inspected URL, viewport, and workflow are clearly identified.
- The review observes rendered behavior, not only source code assumptions.
- Findings are tied to practical user impact for Renan/team/client.
- Mobile ergonomics are checked: tap targets, scrolling, sticky actions, text fit, modals, and form effort.
- Feedback states are checked: save, validation, copy, upload, empty state, and error state when applicable.
- Private data, photos, configs, tokens, and production boundaries are considered.
- Recommendations are local, prioritized, and small enough to review unless explicitly labeled as structural or future.
- No destructive, production, migration, or external-account action is taken without explicit approval.

## Result Format

- Pass / Warning / Fail
- Reviewed route and viewport
- Flow tested
- Strong points
- UX issues
- Recommended local changes
- Safety or testing limits

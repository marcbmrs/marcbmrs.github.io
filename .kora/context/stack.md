## Current Known Stack

Based on local repository structure, Marcos Dev currently includes static web assets and project folders using:

- HTML;
- CSS;
- JavaScript;
- GitHub Pages-style routing;
- `index.html` as the official root site;
- `assets/`, `styles/`, and `scripts/` for shared official-site assets;
- `projetos/` for client projects, demos, campaign pages, and independent deliverables.

Additional folders indicate adjacent operational content or workflows, including:

- `briefing/`;

- `conteudos/`;

Some client/project subfolders may include additional stacks. Confirm before editing or generalizing.

## Quality Priorities

- Responsive mobile-first layout.
- Clear offer and contact path.
- Accessible color contrast and keyboard navigation.
- Fast image loading with optimized assets.
- Stable GitHub Pages URLs.
- No credentials or private client data in the public repository.

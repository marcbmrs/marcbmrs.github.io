# Skill: Optimize Renan Service Catalog

## Purpose

Improve the services and equipment catalog used in Renan Reformas budgets so it is compact, searchable, and comfortable on mobile.

## Procedure

1. Inspect current services/equipment source, UI rendering, category filters, search behavior, and selected-item summary.
2. Preserve existing prices, units, and calculation behavior unless Marcos approves a pricing change.
3. Group or filter services around practical renovation categories such as base, reboco, pisos, demolição, acabamento, solda, and locação.
4. Prefer shorter visible labels, useful metadata, and progressive disclosure over a long full list.
5. Check mobile behavior: horizontal filter scroll, search field, empty states, item tap targets, and selected items summary.
6. Flag any change that affects historical item names, saved budgets, or PDF output.

## Output

Catalog recommendations or implementation summary with grouping, UI impact, pricing risk, and validation performed.

# Skill: Prepare CanteiroPro Demo

## Purpose

Prepare a neutral CanteiroPro demo from the Renan panel without exposing client-specific brand, private data, or production credentials.

## Procedure

1. Start from the Renan panel flow as reference, not as a public clone.
2. Replace Renan-specific naming, logos, colors, copy, catalog examples, and client data with neutral demo equivalents.
3. Preserve the core flow: quote, PDF, status, contract draft, work tracking, client private page, photos, WhatsApp guidance.
4. Keep demo data fictional and visibly safe.
5. Exclude `config.local.php`, production credentials, private photos, real customer tokens, and local-only files.
6. Validate mobile-first screenshots for the main operator flow and client page.
7. Mark legal contract content as draft/reference only.

## Output

Demo preparation checklist with files changed, data safety review, flow coverage, visual validation, and remaining risks.

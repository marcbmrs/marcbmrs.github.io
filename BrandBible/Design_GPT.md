## Direção de arte e identidade visual

# OBJETIVO

Este capítulo define como o GPT deve pensar, criar, avaliar e revisar imagens para:

- carrosséis;
- Stories;
- Reels;
- capas;
- anúncios;
- landing pages;
- mockups;
- materiais institucionais;
- demonstrações do produto.

O objetivo não é criar artes bonitas isoladamente.

O objetivo é construir uma identidade visual reconhecível, funcional e consistente.

Cada imagem precisa ajudar a:

- compreender;
- sentir;
- visualizar;
- lembrar;
- confiar;
- continuar consumindo o conteúdo.

---

# PRINCÍPIO CENTRAL

Visual clean não significa visual vazio.

Significa que cada elemento possui uma função clara.

Uma imagem, ilustração, fotografia ou mockup só deve entrar quando acrescentar algo que o texto sozinho não consegue entregar com a mesma força.

Nunca adicionar elementos apenas para preencher espaço.

---

# IDENTIDADE VISUAL PRINCIPAL

A identidade visual do Marcar Hora deve transmitir:

- simplicidade;
- organização;
- tranquilidade;
- sofisticação;
- proximidade;
- clareza;
- profissionalismo;
- tecnologia acessível.

A marca não deve transmitir:

- complexidade;
- excesso de recursos;
- frieza tecnológica;
- publicidade agressiva;
- infantilidade;
- poluição visual;
- informalidade exagerada;
- aparência de template genérico.

---

# REFERÊNCIAS DE ESTILO

As referências visuais podem se inspirar em princípios presentes em marcas como:

- Apple;
- Linear;
- Stripe;
- Notion;
- Raycast.

Isso não significa copiar layouts.

Significa adotar princípios como:

- hierarquia clara;
- espaços generosos;
- poucos elementos;
- tipografia forte;
- contraste controlado;
- interfaces limpas;
- uso intencional da cor;
- acabamento preciso.

---

# SISTEMA DE VARIAÇÃO VISUAL

O perfil não deve parecer uma sequência de pôsteres tipográficos idênticos.

A identidade precisa permanecer constante.

A execução visual precisa variar.

Os conteúdos devem alternar entre:

- tipografia predominante;
- fotografia realista;
- ilustração minimalista;
- interface real do produto;
- comparação visual;
- cálculo;
- linha do tempo;
- notificações;
- cenas da rotina;
- elementos contextuais discretos.

A identidade visual deve ser reconhecida pela linguagem.

Não pela repetição exata do mesmo layout.

---

# DISTRIBUIÇÃO EDITORIAL RECOMENDADA

Como orientação geral:

- 40% tipografia predominante;
- 30% fotografia ou cena da rotina;
- 20% interface real do produto;
- 10% ilustrações explicativas.

Essa distribuição não é uma regra matemática.

Serve para evitar:

- monotonia;
- feed excessivamente abstrato;
- catálogo de software;
- repetição de smartphone;
- excesso de texto puro.

---

# COMO ESCOLHER ENTRE TEXTO E IMAGEM

Usar somente texto quando:

- a frase já é visual;
- a pausa é importante;
- a simplicidade aumenta impacto;
- qualquer imagem reduziria força.

Usar imagem quando:

- existe uma cena;
- existe emoção;
- existe ação;
- existe comparação;
- existe algo difícil de imaginar;
- o conteúdo precisa de prova.

Usar ilustração quando:

- existe conceito;
- existe cálculo;
- existe fluxo;
- a fotografia seria desnecessária.

Usar interface quando:

- o público precisa compreender o produto;
- a facilidade precisa ser demonstrada.

---

# TESTE DE NECESSIDADE DO ELEMENTO

Antes de adicionar qualquer imagem, perguntar:

1. O elemento acrescenta informação?
2. Ajuda a visualizar a situação?
3. Aumenta identificação?
4. Melhora compreensão?
5. Reforça a emoção?
6. Continua alinhado à marca?

Se a resposta for “não” para a maioria, remover.

---

# TESTE DE REMOÇÃO

Depois da arte pronta, remover mentalmente cada elemento.

Perguntar:

“Se eu retirar isso, a mensagem perde força ou clareza?”

Se não perder, o elemento provavelmente é decorativo.

---

# TESTE DE MINIATURA

Reduzir a arte para o tamanho aproximado em que aparecerá no feed.

Verificar:

- o título ainda é legível?
- a palavra principal ainda aparece?
- a imagem ainda é compreendida?
- a hierarquia continua clara?
- existe excesso de detalhes?

Se não funcionar em miniatura, simplificar.

---

# TESTE DE TRÊS SEGUNDOS

Mostrar a arte rapidamente.

Depois perguntar:

- Qual foi a primeira frase vista?
- Qual era a ideia?
- Qual elemento chamou atenção?
- O tema ficou claro?

Se a resposta não corresponder ao objetivo, revisar.

---

# CRÍTICA VISUAL

O GPT deve ser crítico.

Nunca responder apenas:

“Ficou lindo.”

Deve dizer:

- o que funciona;
- o que não funciona;
- qual elemento compete;
- onde existe excesso;
- qual palavra está fraca;
- se a imagem agrega;
- se existe monotonia;
- se a arte parece propaganda;
- se a promessa é clara.

E depois fornecer ordens exatas para ajuste.

---

# VARIAÇÃO SEM PERDA DE IDENTIDADE

Para evitar monotonia:

- mudar o recurso visual;
- manter a paleta;
- manter a tipografia;
- manter a hierarquia;
- manter o tom;
- manter a simplicidade.

Exemplo de sequência:

Slide 1:

tipografia.

Slide 2:

fotografia.

Slide 3:

tipografia.

Slide 4:

fragmentos de mensagens.

Slide 5:

ilustração.

Slide 6:

cálculo.

Slide final:

interface real.

Isso gera ritmo sem perder identidade.

---

# REGRA DE CONSISTÊNCIA

Uma arte pode ser diferente das anteriores.

Mas nunca pode parecer de outra marca.

A pergunta correta não é:

“Está igual?”

É:

“Pertence ao mesmo sistema visual?”

---

# REGRA FINAL

Toda imagem deve justificar sua presença.

Quando o texto for suficiente, utilizar texto.

Quando a cena for necessária, utilizar fotografia.

Quando a ideia precisar ser explicada, utilizar ilustração.

Quando o produto precisar ser provado, utilizar interface real.

Nunca adicionar elementos apenas para deixar a arte menos vazia.


## Composição e sistema visual

# HIERARQUIA VISUAL

Cada arte deve possuir um protagonista.

Pode ser:

- uma pergunta;
- uma palavra;
- um número;
- uma cena;
- uma tela;
- uma comparação;
- uma ilustração.

Nunca permitir que vários elementos disputem atenção.

Antes de aprovar, perguntar:

“O que deve ser visto primeiro?”

Se a resposta não estiver clara, o layout precisa ser simplificado.

---

# TIPOGRAFIA

A tipografia deve ser:

- moderna;
- limpa;
- legível;
- elegante;
- sem excesso de variações;
- com hierarquia evidente.

Preferir:

- títulos grandes;
- frases curtas;
- poucos pesos;
- bom espaçamento;
- alinhamento consistente.

Evitar:

- fontes manuscritas;
- fontes decorativas;
- fontes infantis;
- excesso de itálico;
- várias famílias tipográficas na mesma arte;
- letras extremamente finas em textos pequenos.

---

# TIPO VISUAL 01

# TIPOGRAFIA PREDOMINANTE

Usar quando:

- uma frase é suficiente;
- o objetivo é posicionamento;
- existe uma pergunta forte;
- queremos quebrar o padrão;
- o conteúdo precisa de silêncio;
- o texto já cria a imagem mental.

Exemplos:

- “O problema nunca foi você.”
- “Sua agenda está cheia. E sua conta?”
- “Mais presença. Menos interrupções.”

## Direção visual

- muito espaço em branco;
- uma palavra em lilás;
- poucas linhas;
- sem ícones;
- sem ilustrações;
- sem celular;
- sem logo grande.

## Risco

Virar repetitivo.

Não utilizar em todos os posts.

---

# ESPAÇO EM BRANCO

Espaço em branco não é ausência.

É hierarquia.

Ele deve ser utilizado para:

- separar ideias;
- aumentar percepção de qualidade;
- orientar leitura;
- criar pausa;
- destacar palavras;
- reduzir fadiga.

Nunca preencher todo espaço disponível apenas porque ele existe.

---

# PALETA PRINCIPAL

## Cor principal

Lilás:

`#A855F7`

Pode ser usada para:

- palavras-chave;
- destaques;
- seleções;
- detalhes de interface;
- linhas;
- pequenos elementos gráficos;
- pontos focais.

Nunca utilizar em excesso.

A cor deve orientar o olhar.

Não dominar toda a composição.

## Cores de apoio

- branco;
- preto;
- tons de cinza muito suaves;
- lilases de baixa opacidade;
- fundos claros com textura discreta.

Evitar adicionar novas cores sem função estratégica.

---

# FUNDO

O fundo padrão deve ser:

- branco;
- claro;
- limpo;
- com textura muito suave;
- sem gradientes fortes;
- sem manchas decorativas excessivas;
- sem elementos competindo com o conteúdo.

Gradientes podem aparecer de forma quase imperceptível.

Exemplo:

branco para lilás muito claro.

Nunca utilizar fundos pesados apenas para tornar a arte “mais chamativa”.

---

# TIPO VISUAL 03

# ILUSTRAÇÃO MINIMALISTA

Usar quando:

- o conceito precisa ser explicado;
- uma fotografia seria literal demais;
- existe cálculo;
- existe fluxo;
- existe comparação;
- queremos representar tempo;
- queremos mostrar acúmulo;
- queremos visualizar organização.

## Exemplos

- relógio segmentado;
- linha do tempo;
- agenda com espaços;
- blocos de horários;
- mensagens se acumulando;
- fluxo em três passos;
- calendário simplificado;
- tarefa dividida em pequenos fragmentos;
- tempo administrativo;
- antes e depois da agenda.

## Direção visual

- linhas finas;
- poucos elementos;
- lilás apenas no destaque;
- desenho geométrico;
- sem aparência infantil;
- sem estilo cartoon;
- sem excesso de sombra;
- sem tridimensionalidade exagerada.

---

# TIPO VISUAL 05

# ELEMENTOS CONTEXTUAIS

São pequenos elementos que ajudam a criar ambiente.

Exemplos:

- balões de mensagens desfocados;
- horários;
- pequenos calendários;
- notificações;
- linhas;
- marcas de seleção;
- campos;
- fragmentos de interface;
- pequenos pontos de cor;
- sombras suaves.

## Função

- ambientar;
- sugerir;
- reforçar;
- criar contexto;
- aumentar identificação.

## Regra

Devem continuar secundários.

Se o elemento chama mais atenção que a mensagem, reduzir ou remover.

---

# TIPO VISUAL 06

# COMPARAÇÃO VISUAL

Usar quando:

- existe antes e depois;
- existe rotina atual e possível;
- existe WhatsApp e agendamento;
- existe agenda desorganizada e organizada;
- existe excesso e simplicidade.

## Estrutura possível

Lado A:

- mensagens;
- interrupção;
- troca manual;
- vários passos.

Lado B:

- fluxo simples;
- seleção;
- confirmação;
- notificação.

## Evitar

- comparação humilhante;
- usar “errado” e “certo” de forma agressiva;
- ridicularizar WhatsApp;
- dramatizar o caos;
- apresentar solução perfeita.

Preferir:

“Hoje”

e

“Como poderia ser”.

---

# TIPO VISUAL 07

# CÁLCULO E DADOS

Usar quando:

- existe valor prático;
- existe fórmula;
- existe estimativa;
- queremos transformar sensação em número.

## Direção visual

- uma conta por slide;
- números grandes;
- linhas finas;
- explicação curta;
- deixar claro quando for exemplo;
- evitar moedas;
- evitar calculadoras;
- evitar gráficos de coach;
- evitar aparência escolar.

## Exemplo

30 minutos por dia  
× 22 dias  
= 11 horas por mês

---

# ELEMENTOS QUE DEVEM SER EVITADOS

Evitar elementos clichês como:

- foguetes;
- lâmpadas;
- troféus;
- moedas voando;
- gráficos genéricos;
- setas ascendentes sem contexto;
- sacos de dinheiro;
- relógios dramáticos;
- correntes quebrando;
- alvo;
- megafone;
- robôs;
- cérebro digital;
- engrenagens;
- ícones aleatórios;
- confetes;
- selos chamativos.

Esses elementos reduzem a percepção premium e aproximam a marca de conteúdos genéricos de marketing digital.

---

# USO DA LOGO

A logo deve aparecer:

- no último slide;
- em conteúdo institucional;
- em demonstrações;
- em capas quando necessário;
- em materiais oficiais.

Evitar logo grande em:

- conteúdos educativos;
- primeiros slides;
- manifestos;
- Stories de relacionamento;
- peças tipográficas.

## Regras

- usar arquivo original;
- não redesenhar;
- não alterar proporções;
- não trocar tipografia;
- não mudar símbolo;
- não aplicar efeitos;
- não adicionar contorno;
- não criar versão alternativa sem autorização.

---

# ACESSIBILIDADE

Toda arte deve considerar:

- contraste suficiente;
- fonte legível;
- texto grande;
- poucas palavras;
- margens seguras;
- leitura em telas pequenas;
- ausência de texto importante próximo às bordas;
- destaque não dependente apenas da cor.

Evitar textos muito claros em fundo branco.

---

# FORMATOS

## Carrossel

- 1080 × 1350;
- proporção 4:5;
- margens seguras;
- texto legível em miniatura;
- capa reconhecível no feed.

## Story e Reel

- 1080 × 1920;
- proporção 9:16;
- respeitar áreas cobertas pela interface do Instagram;
- não colocar texto principal muito próximo do topo ou rodapé.

## Post quadrado

Usar apenas quando fizer sentido.

O formato 4:5 costuma oferecer mais área no feed.

---

# SISTEMA DE CAPAS

A capa deve:

- funcionar sem legenda;
- ser entendida em menos de dois segundos;
- criar curiosidade;
- possuir pouco texto;
- ser legível na grade;
- evitar excesso de elementos;
- não explicar todo o conteúdo.

## Tipos de capa

### Pergunta

“Sua agenda está cheia.  
E sua conta?”

### Contradição

“Mais clientes.  
Mesmo lucro.”

### Observação

“Cinco minutos parecem pouco.”

### Manifesto

“O problema nunca foi você.”

### Cena

Smartphone com mensagens e uma frase curta.

---


## Contexto de uso visual

# USO DE SMARTPHONE

O smartphone deve ser usado com moderação.

Ele é útil para:

- demonstrar fluxo;
- mostrar a visão da cliente;
- apresentar uma notificação;
- contextualizar uma ação digital.

Não deve aparecer:

- em todos os slides;
- ocupando quase toda a composição;
- apenas para deixar claro que existe um aplicativo;
- girando em 3D;
- com sombras exageradas;
- com perspectiva impossível.

## Tamanho recomendado

Normalmente entre 25% e 45% da composição.

Pode variar conforme o objetivo.

---

# TIPO VISUAL 02

# FOTOGRAFIA REALISTA

Usar quando:

- a cena precisa ser sentida;
- existe uma interação humana;
- queremos mostrar rotina;
- existe conflito entre profissional, cliente e celular;
- o objetivo é identificação emocional.

## Cenas recomendadas

- manicure atendendo enquanto o celular vibra;
- cliente esperando discretamente;
- profissional focada no atendimento;
- celular ao lado, desfocado;
- cliente escolhendo horário no próprio celular;
- profissional finalizando um procedimento;
- ambiente real de beleza;
- momento de pausa;
- rotina organizada;
- atendimento sem interrupções.

## Direção visual

As fotografias devem parecer:

- reais;
- naturais;
- elegantes;
- calmas;
- profissionais;
- levemente editoriais;
- sem excesso de pose;
- sem cara de banco de imagens.

## Evitar

- sorrisos artificiais;
- cenários perfeitos demais;
- pessoas olhando diretamente para a câmera sem motivo;
- equipamentos aleatórios;
- unhas ou procedimentos representados incorretamente;
- excesso de maquiagem ou glamour;
- ambiente de luxo incompatível com o público;
- cenas irreais;
- mãos deformadas;
- cliente com expressão dramática.

---

# FOTOGRAFIA E REPRESENTAÇÃO DO NICHO

Quando o conteúdo for para nail designers e manicures, garantir:

- mesa de atendimento coerente;
- iluminação de trabalho;
- posição real das mãos;
- materiais compatíveis;
- ambiente profissional;
- cliente sentada corretamente;
- profissional em posição plausível;
- unhas realistas;
- ausência de deformações;
- contexto brasileiro quando relevante.

Não utilizar imagens que pareçam:

- salão de luxo estrangeiro;
- clínica médica;
- spa genérico;
- procedimento não relacionado;
- modelo publicitária em vez de profissional real.

---

# HUMANIDADE VISUAL

A marca não deve parecer perfeita demais.

Pequenas imperfeições controladas podem aumentar autenticidade:

- notificação desfocada;
- mensagem incompleta;
- horário real;
- leve assimetria;
- cena espontânea;
- ambiente vivido;
- objeto fora do alinhamento perfeito;
- luz natural.

Nunca confundir humanidade com descuido.

---

# TIPO VISUAL 04

# INTERFACE REAL DO PRODUTO

Usar quando:

- o objetivo é demonstrar;
- existe uma funcionalidade relevante;
- a pergunta já foi construída;
- o público precisa entender como funciona;
- é necessário provar simplicidade.

## Telas prioritárias

- escolha do serviço;
- escolha da data;
- escolha do horário;
- confirmação dos dados;
- solicitação enviada;
- notificação recebida;
- agenda organizada.

## Regras obrigatórias

- utilizar telas reais;
- preservar textos reais;
- preservar cores reais;
- preservar proporções;
- não redesenhar sem autorização;
- não inventar funcionalidades;
- não alterar dados relevantes;
- não mostrar tela antiga como atual;
- não criar experiência mais simples do que a verdadeira.

## O mockup deve

- apoiar a mensagem;
- ocupar espaço controlado;
- ser legível;
- parecer real;
- nunca dominar a peça.

# COMO O GPT DEVE CRIAR PROMPTS

O prompt deve conter:

1. formato;
2. objetivo;
3. contexto;
4. mensagem;
5. estilo;
6. elemento visual;
7. hierarquia;
8. cores;
9. restrições;
10. o que não fazer;
11. emoção;
12. relação com os slides anteriores.

Nunca entregar apenas:

“Crie uma arte bonita e moderna.”

Isso é genérico e insuficiente.

# COMO O GPT DEVE AVALIAR UMA ARTE ENVIADA

A análise deve separar:

## Mensagem

A copy funciona?

## Hierarquia

O olhar segue a ordem correta?

## Composição

Existe equilíbrio?

## Identidade

Parece Marcar Hora?

## Elementos

Cada elemento possui função?

## Legibilidade

Funciona no celular?

## Continuidade

Combina com os outros slides?

## Retenção

Faz a pessoa continuar?

## Risco

Parece propaganda, template ou conteúdo genérico?

Depois indicar exatamente:

- o que manter;
- o que remover;
- o que reduzir;
- o que aumentar;
- o que substituir;
- qual ordem utilizar.

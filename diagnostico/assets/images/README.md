# Assets visuais do Diagnóstico

A página atual funciona com ilustrações em CSS. As imagens abaixo são melhorias narrativas opcionais; não incluir apenas por decoração.

## Onde salvar

1. Salvar a imagem-fonte em `C:\MarcosDev-Originais\site-marcos-dev\images\diagnostico\`.
2. Pedir: **"Otimize as imagens originais do Diagnóstico de Presença Digital para o site."**
3. Salvar as versões derivadas aqui, usando os nomes `hero-jornada`, `indicacao-pesquisa` e `clareza-contato`, nos formatos AVIF e WebP.
4. Só então inserir no HTML com `picture`, dimensões declaradas e `loading="lazy"` fora da primeira tela. A imagem hero não usa lazy loading.

## Prompt — `hero-jornada`

```text
Use case: illustration-story
Asset type: imagem hero para ferramenta de diagnóstico de presença digital de pequenos negócios locais.
Primary request: ilustração editorial horizontal ampla, sem texto, mostrando três pessoas abstratas chegando pela esquerda; um caminho azul passa por cartões de informação incompletos e para antes de alcançar um ponto de contato à direita. A ideia é: pessoas podem chegar, mas o caminho até a conversa ainda pode estar incompleto.
Scene/backdrop: fundo azul-marinho, muito espaço negativo no lado esquerdo para texto HTML.
Style/medium: ilustração editorial madura com cel shading sutil, contornos visíveis, formas levemente simplificadas e sombras planas; não fotográfica.
Composition/framing: fluxo ocupa o terço direito; espaço vazio limpo no lado esquerdo.
Color palette: #0B1F3A dominante, #2563EB no caminho, #14B8A6 em dois pontos discretos, #F8FAFC nos cartões.
Constraints: sem palavras, letras, números, marcas, logos, pseudoescrita, dashboards, métricas, alertas, setas agressivas ou marca-d'água.
```

## Prompt — `indicacao-pesquisa`

```text
Use case: illustration-story
Asset type: seção explicativa de landing page.
Primary request: ilustração editorial sem texto de uma pessoa adulta fictícia recebendo uma indicação em conversa informal e depois olhando o celular para confirmar informações de uma empresa local. A pessoa é parte da narrativa, não modelo publicitária.
Scene/backdrop: contexto brasileiro cotidiano, ambiente funcional de trabalho ou casa, objetos plausíveis e discretos.
Style/medium: ilustração editorial madura com cel shading sutil, perfil de três quartos, traços simplificados, sem rosto hiper-realista.
Composition/framing: horizontal, pessoa e celular à direita, espaço livre à esquerda para texto HTML.
Color palette: azul-marinho, azul, verde-água controlado, fundo claro.
Constraints: sem texto, logos, interface legível, pseudoescrita, marcas, dinheiro, gráficos, estética de banco de imagens ou marca-d'água.
```

## Prompt — `clareza-contato`

```text
Use case: illustration-story
Asset type: seção explicativa de landing page.
Primary request: ilustração editorial sem texto representando informações de serviço, região, prova e contato organizadas como quatro cartões abstratos conectados, levando naturalmente a um ponto de contato abstrato. Comunicar clareza e próximo passo, sem promessa de resultado.
Scene/backdrop: interface abstrata humanizada sobre fundo claro, sem dashboard real.
Style/medium: ilustração editorial adulta com cel shading sutil, formas geométricas organizadas, contornos limpos e sombras planas leves.
Composition/framing: horizontal, fluxo da esquerda para a direita, bastante respiro para texto HTML.
Color palette: #F8FAFC predominante, #0B1F3A para estrutura, #2563EB e #14B8A6 como acentos controlados.
Constraints: sem palavras, letras, números, pseudoescrita, logos, métricas, gráficos, alertas, marcas inventadas ou marca-d'água.
```

# Valores

## Honestidade

Nunca prometer resultados irreais.

Nunca manipular números.

Nunca usar urgência falsa.

Nunca criar provas sociais falsas.

---

## Simplicidade

A melhor solução normalmente é a mais simples.

O conteúdo deve refletir isso.

---

## Clareza

O cliente nunca deve terminar um conteúdo com dúvidas.

Complexidade é um defeito.

---

## Respeito pelo tempo

Cada segundo da cliente importa.

Cada segundo do leitor também.

Todo conteúdo deve justificar o tempo investido.

---

## Elegância

O Marcar Hora nunca grita.

Nunca exagera.

Nunca parece desesperado para vender.

Elegância transmite confiança.

---

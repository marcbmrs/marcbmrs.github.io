# Psicóloga — projeto demonstrativo

## Finalidade

Demonstrar uma estrutura ética e acolhedora para o site de uma profissional de psicologia. Não representa clínica, profissional, atendimento ou dados reais.

## Estado

Estrutura inicial pronta para revisão. Antes de qualquer uso como site real, substituir todos os conteúdos demonstrativos por informações confirmadas da profissional, incluindo nome, CRP, formação, abordagem, modalidades, contato, avisos e foto autorizada.

## Arquivos principais

- `index.html`: conteúdo e estrutura semântica da demonstração.
- `styles/main.css`: identidade visual, responsividade e movimento reduzido.

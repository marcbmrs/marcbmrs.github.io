## Aprendizados

Listar apenas aprendizados reutilizáveis.

Exemplo.

✓ A primeira pergunta foi boa.

✓ O produto apareceu cedo demais.

✓ Houve excesso de explicação.

---

# NÃO REESCREVER TUDO

O GPT não deve apagar toda a conversa.

Apenas corrigir os pontos que realmente fariam diferença.

O objetivo é melhorar o vendedor.

Não criar uma conversa perfeita artificialmente.

---

# BANCO DE APRENDIZADOS

Sempre que uma conversa terminar.

Gerar um aprendizado.

Exemplo.

Conversa 014

Aprendizado.

"A profissional respondeu melhor quando a pergunta foi específica."

--------------------------------

Conversa 022

Aprendizado.

"O link foi enviado cedo demais."

--------------------------------

Conversa 031

Aprendizado.

"O elogio genérico reduziu a naturalidade."

--------------------------------

Conversa 047

Aprendizado.

"A profissional respondeu imediatamente quando a primeira mensagem foi baseada em uma observação real."

Esses aprendizados devem servir para melhorar futuras abordagens.

---

# EVOLUÇÃO CONTÍNUA

Quando o GPT analisar muitas conversas.

Deve começar a identificar padrões.

Exemplos.

As nail designers respondem melhor a...

As esteticistas costumam perguntar...

As profissionais iniciantes possuem mais dúvidas sobre...

Os principais motivos de perda de venda são...

Essas conclusões só devem ser apresentadas quando existirem evidências suficientes.

Nunca por impressão.

---

# REGRA FINAL

A primeira mensagem não deve abrir uma venda.

Ela deve abrir uma conversa.

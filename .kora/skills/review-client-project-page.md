# Skill: Review Client Project Page

## Purpose

Review pages and assets under `projetos/<nome-do-projeto>/` before delivery or publication.

## Procedure

1. Identify the project folder and public URL expectation.
2. Read the project README if present.
3. Confirm local structure: `index.html`, optional `assets/`, `styles/`, `scripts/`, and no unnecessary empty folders.
4. Check client-specific copy, links, CTA, images, responsiveness, performance, SEO basics, and asset naming.
5. Confirm no private source images, notes, credentials, unpublished data, or unrelated project files are included.
6. Note required README or sitemap updates when routes change.

## Output

Client project page review with readiness status and exact files needing attention.

# Plano de Conteúdo para Instagram

## Finalidade

Página pública para reunir o contexto necessário para planejar uma identidade visual e uma linha editorial de Instagram. As respostas permanecem no navegador até a pessoa escolher abrir a mensagem no WhatsApp.

## URL pública esperada

`https://marcosdevweb.com.br/conteudo-instagram/`

## Arquivos principais

- `index.html`: estrutura, formulário e metadados de compartilhamento.
- `styles/main.css`: layout responsivo e seleção visual de paleta.
- `scripts/main.js`: validação e montagem da mensagem para WhatsApp.
- `../assets/images/plano-conteudo-instagram-compartilhamento.png`: imagem exibida ao compartilhar o link.

## Estado

Pronto para revisão local. O formulário não armazena dados nem pede acesso à conta do Instagram.

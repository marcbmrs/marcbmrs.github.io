# Marcos Dev KORA Memory

This directory is reserved for Marcos Dev-specific operational memory.

Do not store raw transcripts or low-value notes here.

Store only useful, durable learning that helps future work on Marcos Dev.

## Level 7 Persistence Rules

KORA level 7 is active for Marcos Dev as of 2026-09-05.

Persist only records that are useful for future work, such as:

- accepted project decisions;
- formal eval results;
- completed experiment outcomes;
- recurring capability gaps;
- learning recommendations tied to Marcos Dev workflows.

Do not persist:

- raw chat transcripts;
- temporary notes;
- secrets, credentials, tokens, or private account access;
- unnecessary personal or client data;
- broad knowledge that belongs in MarcosOS or KORA Core.

Each durable record should state date, scope, evidence or source, decision or learning, and next recommended action when relevant.

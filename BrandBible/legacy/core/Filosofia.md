# O que é o Marcar Hora?

O Marcar Hora é um SaaS de agendamento.

Mas isso não define a marca.

O produto é um software.

A marca é uma ideia.

O Marcar Hora existe para devolver tempo às profissionais que vivem cuidando de pessoas.

Não vende agenda.

Não vende calendário.

Não vende tecnologia.

Vende tranquilidade.

Vende organização.

Vende presença.

Vende uma rotina melhor.

Todo conteúdo criado deve reforçar essa ideia.

Nunca o contrário.

---

# A verdadeira transformação

O cliente não compra um sistema.

Ele compra uma transformação.

Antes do Marcar Hora:

- responde mensagens durante atendimentos;
- interrompe conversas;
- procura horários;
- faz encaixes manualmente;
- confirma horários pelo WhatsApp;
- reorganiza atrasos;
- sente que trabalha muito.

Depois do Marcar Hora:

- dedica mais atenção ao atendimento;
- reduz interrupções;
- organiza melhor a agenda;
- transmite mais profissionalismo;
- ganha previsibilidade;
- trabalha com mais tranquilidade.

Essa transformação é mais importante do que qualquer funcionalidade.

---

# O inimigo da marca

Toda marca forte possui um inimigo.

O inimigo do Marcar Hora não são outros aplicativos.

Não é a concorrência.

Não é o papel.

Não é a agenda física.

O verdadeiro inimigo é:

A rotina desorganizada.

Mais especificamente:

- interrupções constantes;
- excesso de mensagens;
- tarefas repetitivas;
- pequenas perdas de tempo;
- sensação de viver apagando incêndios.

Toda comunicação deve combater esse inimigo.

Nunca um concorrente.

---

# O propósito

Devolver presença.

Quando uma profissional consegue olhar para a cliente sem interromper o atendimento para responder mensagens, o Marcar Hora cumpriu seu propósito.

Esse é o verdadeiro sucesso do produto.

Não o número de usuários.

---

# O que o Marcar Hora NÃO é

Não é um aplicativo de agenda.

Não é um sistema complicado.

Não é um ERP.

Não é um software financeiro.

Não é um CRM.

Não é uma empresa de tecnologia.

É uma empresa que resolve um problema humano utilizando tecnologia.

Essa diferença muda completamente a comunicação.

---

# Como queremos que a marca seja percebida

Quando alguém visita o perfil do Marcar Hora deve pensar:

"Essas pessoas entendem exatamente a minha rotina."

Não:

"Eles têm um aplicativo bonito."

---

# Como NÃO queremos ser percebidos

Como vendedores de software.

Como empresa que publica funcionalidades.

Como perfil que faz propaganda todos os dias.

Como perfil motivacional.

Como perfil genérico de empreendedorismo.

---

# O sentimento que toda publicação deve gerar

Cada publicação precisa provocar pelo menos um destes sentimentos:

✔ identificação

✔ alívio

✔ descoberta

✔ clareza

✔ esperança

Nunca produzir conteúdo apenas para preencher calendário.

Todo conteúdo precisa melhorar a percepção da marca.

---

# FILOSOFIA

Toda marca forte possui limites.

O Marcar Hora não busca crescer a qualquer custo.

O objetivo não é produzir mais conteúdo.

O objetivo é construir confiança.

Se uma estratégia aumentar alcance, mas diminuir confiança, ela deve ser descartada.

A reputação sempre vale mais que o alcance.

# REGRA DE ABERTURA

A primeira linha deve funcionar mesmo quando aparece sozinha na prévia da legenda.

Ela precisa:

- criar continuidade;
- gerar curiosidade;
- reforçar uma observação;
- ou apresentar uma nuance.

Exemplos aprovados:

- “O problema raramente é uma única tarefa.”
- “Uma agenda cheia pode esconder muito trabalho invisível.”
- “Nem toda conversa precisa desaparecer.”
- “Organizar não significa deixar o atendimento impessoal.”
- “A cliente não precisa conhecer sua rotina para sentir seus efeitos.”

---

# ABERTURAS REJEITADAS

- “Olá, profissionais da beleza!”
- “Passando para compartilhar...”
- “Você sabia?”
- “Dica de hoje:”
- “Confira esse conteúdo incrível.”
- “Mais uma novidade para vocês.”
- “Quer transformar seu negócio?”
- “Chegou a hora de revolucionar sua agenda.”

Essas frases são genéricas e desperdiçam a primeira linha.

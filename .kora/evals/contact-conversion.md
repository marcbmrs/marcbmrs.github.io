# Eval: Contact Conversion

## Purpose

Evaluate whether a page gives users a clear, trustworthy path to contact Marcos Dev.

## Criteria

- Primary CTA is visible and specific.
- WhatsApp links use E.164 digits only in `https://wa.me/` URLs.
- Contact options match the page intent.
- Forms or links avoid collecting unnecessary sensitive data.
- Copy prepares the user for the next step.
- No external platform behavior is assumed without verification when current details matter.

## Result Format

- Pass / Warning / Fail
- CTA reviewed
- Issues
- Recommended correction

# Site odontológico demonstrativo

## Finalidade

Projeto conceitual da Marcos Dev para demonstrar uma estrutura de site odontológico que prioriza informação clara, confiança e caminho de contato. Não representa clínica, profissional, atendimento ou serviço real.

## Estado

Protótipo estático inicial. Não possui formulário funcional, agendamento, dados pessoais, imagens de pacientes, depoimentos, CRO, localização ou promessas de resultado.

## Arquivos principais

- `index.html` — estrutura semântica e conteúdo demonstrativo.
- `styles/main.css` — identidade visual, responsividade e acessibilidade básica.

## URL pública esperada

`https://marcbmrs.github.io/projetos/site-odontologico-demonstrativo/`

## Antes de publicar

Revisar visualmente em celular e desktop, checar links e teclado e confirmar que a página permanece identificada como demonstração. A publicação depende de autorização explícita do titular.

# CHECKLIST

Toda publicação deve responder:

✔ Qual crença estou reforçando?

✔ Qual crença estou mudando?

✔ A mudança acontece naturalmente?

✔ Existe uma observação que sustenta essa mudança?

Se qualquer resposta for negativa, revisar o conteúdo.

# CHECKLIST DA LEGENDA

Antes de aprovar:

- A primeira linha funciona sozinha?
- A legenda complementa em vez de repetir?
- Existe apenas uma ideia principal?
- O texto parece humano?
- Há alguma promessa exagerada?
- A linguagem está simples?
- O CTA combina com o objetivo?
- A pergunta é específica?
- Existe excesso de texto?
- O produto aparece no momento correto?
- A legenda parece Marcar Hora?

Se qualquer resposta for negativa, reescrever.

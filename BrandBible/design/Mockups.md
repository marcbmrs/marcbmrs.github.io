# TIPO VISUAL 04

# INTERFACE REAL DO PRODUTO

Usar quando:

- o objetivo é demonstrar;
- existe uma funcionalidade relevante;
- a pergunta já foi construída;
- o público precisa entender como funciona;
- é necessário provar simplicidade.

## Telas prioritárias

- escolha do serviço;
- escolha da data;
- escolha do horário;
- confirmação dos dados;
- solicitação enviada;
- notificação recebida;
- agenda organizada.

## Regras obrigatórias

- utilizar telas reais;
- preservar textos reais;
- preservar cores reais;
- preservar proporções;
- não redesenhar sem autorização;
- não inventar funcionalidades;
- não alterar dados relevantes;
- não mostrar tela antiga como atual;
- não criar experiência mais simples do que a verdadeira.

## O mockup deve

- apoiar a mensagem;
- ocupar espaço controlado;
- ser legível;
- parecer real;
- nunca dominar a peça.

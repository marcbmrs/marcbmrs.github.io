# Eval: Internal Panel Native App Quality

## Purpose

Evaluate whether a Marcos Dev internal panel behaves like a practical mobile-first app for daily operations.

## Criteria

- The dashboard answers what needs attention today and lets the user resume work quickly.
- Primary workflows can be completed one-handed on mobile with clear sticky actions.
- Navigation has a persistent app structure, obvious active state, and no dead-end screens.
- Forms reduce typing, group optional data, validate inline, and preserve work when possible.
- Lists support search/filter/sort, readable status, empty states, and fast next actions.
- Status transitions are understandable, reversible where appropriate, and protected when destructive.
- Saves, uploads, copies, PDF generation, and WhatsApp actions provide visible feedback.
- Touch targets, focus states, contrast, text size, and motion respect accessibility basics.
- Private configs, credentials, database access, and client photos are not exposed in public files.

## Result Format

- Pass / Warning / Fail
- Panel reviewed
- Strong points
- UX gaps
- Native-app improvements
- Data/security dependencies
- Recommended next implementation batch

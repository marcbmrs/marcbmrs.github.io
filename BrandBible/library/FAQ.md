# FAQ 01
# O QUE É O MARCAR HORA?

O Marcar Hora é um sistema de agendamento online para profissionais que trabalham com horário marcado.

Ele permite que a cliente consulte serviços, datas e horários disponíveis e envie uma solicitação de agendamento por meio de um link.

---

# FAQ 02
# PARA QUEM É O MARCAR HORA?

O foco inicial são profissionais da beleza, como:

- nail designers;
- manicures;
- pedicures;
- esteticistas;
- lash designers;
- designers de sobrancelhas;
- cabeleireiras;
- micropigmentadoras;
- massoterapeutas.

Também pode fazer sentido para outros profissionais que atendem com hora marcada, desde que o fluxo atual do produto seja compatível com a rotina deles.

---

# FAQ 03
# COMO A CLIENTE AGENDA?

A cliente:

1. acessa o link;
2. escolhe o serviço;
3. escolhe a data;
4. escolhe o horário;
5. informa os dados;
6. envia a solicitação.

O GPT deve confirmar se o agendamento entra diretamente como confirmado ou como solicitação pendente antes de explicar essa etapa.

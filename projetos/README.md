# Projetos

Esta pasta reúne sites independentes desenvolvidos no repositório da Marcos Dev.

## Regra de acesso público

Com GitHub Pages publicado a partir deste repositório, a rota padrão de cada projeto é:

`https://marcbmrs.github.io/projetos/<nome-do-projeto>/`

Cada projeto deve manter seu próprio `README.md` com a rota concreta, finalidade e estado. Se futuramente usar domínio próprio ou houver mudança de publicação, atualizar primeiro o README afetado e depois os links externos conhecidos.

# Eval: Site Accessibility and Performance

## Purpose

Evaluate core web quality for Marcos Dev static pages.

## Criteria

- Text contrast is readable.
- Keyboard navigation is not blocked.
- Layout works on mobile and desktop.
- Images have useful `alt` text when informative.
- Hero/first-viewport images are not lazy loaded.
- Images have dimensions and are optimized when practical.
- CSS/JS changes do not create obvious layout shifts or broken interactions.

## Result Format

- Pass / Warning / Fail
- Viewports or checks used
- Findings
- Recommended fix

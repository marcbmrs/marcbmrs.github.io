# HIERARQUIA VISUAL

Cada arte deve possuir um protagonista.

Pode ser:

- uma pergunta;
- uma palavra;
- um número;
- uma cena;
- uma tela;
- uma comparação;
- uma ilustração.

Nunca permitir que vários elementos disputem atenção.

Antes de aprovar, perguntar:

“O que deve ser visto primeiro?”

Se a resposta não estiver clara, o layout precisa ser simplificado.

# Eval: Landing Page Quality

## Purpose

Evaluate whether a landing page is structurally ready for users.

## Criteria

- First viewport communicates brand, offer, and next action.
- Page has coherent hierarchy and scannable sections.
- Mobile layout works without overlap or unreadable text.
- Images and assets load from stable relative paths.
- CTA/contact links work.
- Metadata and public URL assumptions are reasonable.
- Copy does not invent proof, metrics, clients, or guarantees.

## Result Format

- Pass / Warning / Fail
- Page reviewed
- Findings
- Fixes before publish

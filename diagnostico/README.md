# Diagnóstico de Presença Digital

## Finalidade

Página pública da Marcos Dev para uma revisão inicial de presença digital em cinco perguntas. Não gera nota, não armazena respostas e não substitui um diagnóstico completo. O objetivo é indicar um primeiro ponto a revisar antes de escolher uma ferramenta.

## URL pública esperada

`https://marcbmrs.github.io/diagnostico/`

## Estrutura

- `index.html`: conteúdo, estrutura e metadados.
- `styles/main.css`: layout responsivo, sistema visual e animações leves.
- `scripts/main.js`: perguntas, resultado orientativo e link de conversa. Nenhuma resposta sai do navegador.
- `assets/images/README.md`: prompts, nomes e fluxo para assets rasterizados futuros.

## Estado

Implementação inicial pronta para revisão local. A página funciona sem imagens rasterizadas porque usa ilustrações gráficas em CSS. Não publicar antes de testar versão móvel, teclado, os cinco resultados e links do WhatsApp.

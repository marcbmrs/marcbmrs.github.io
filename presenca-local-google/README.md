# Presença Local no Google

## Finalidade

Página pública para reunir as informações iniciais de uma empresa que deseja criar ou organizar seu Perfil da Empresa no Google. Não coleta senhas, códigos ou dados de recuperação. Ao terminar, a pessoa revisa as respostas no WhatsApp antes de enviar.

## URL pública esperada

`https://marcosdevweb.com.br/presenca-local-google/`

## Arquivos principais

- `index.html`: estrutura, conteúdo e metadados.
- `styles/main.css`: layout responsivo e componentes do formulário.
- `scripts/main.js`: validação e mensagem estruturada para WhatsApp.

## Estado

Pronto para revisão local. A criação e a verificação do perfil continuam na Conta Google do cliente; a Marcos Dev recebe apenas acesso de administradora quando necessário.

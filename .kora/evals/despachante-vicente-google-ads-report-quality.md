# Eval: Despachante Vicente Google Ads Weekly Report Quality

## Purpose

Verify that a weekly Despachante Vicente Google Ads report is accurate, client-safe and visually consistent with the established Gamma reporting pattern.

## Pass Criteria

- Uses KORA read-only Google Ads data for the stated current and comparison periods.
- Shows the exact period, comparison period and data-source read date.
- Reconciles impressions, clicks, CTR, investment, CPC and conversions with the source data; tables, cards and charts agree with one another.
- Explains missing daily API rows without converting them into invented performance values.
- Preserves the agreed Gamma system: 16:9 light deck, Despachante Vicente and Marcos Dev branding, cover, executive summary, metric education, scorecards, comparison, charts, daily evolution, operational transparency, strategic reading, next steps and closing.
- Uses direct Brazilian Portuguese suitable for a non-technical client.
- Distinguishes observation, hypothesis, recommendation and approved action.
- Treats WhatsApp clicks as technical conversions, not confirmed contacts, qualified leads or sales.
- Avoids unsupported claims about revenue, ROI, ROAS, sales, ranking or guaranteed outcomes.
- Has been visually reviewed in Gamma before being marked ready.

## Fail Conditions

- A number, date, comparison or chart conflicts with the read-only source data.
- The report is generated from a generic Gamma style when the established Despachante Vicente reference is accessible.
- Private account identifiers, credentials, raw API outputs or unnecessary client data are recorded in the public repository.
- The report implies that Google Ads changes were made or approved when no separate approval exists.
- Gamma is shared, exported or externally distributed without Marcos's explicit instruction.
